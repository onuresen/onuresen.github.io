Prepare a contribution

Professional recommendations require a relationship and benefit disclosure. Inclusion would still be manual and would not mean Town Reboot endorsement.


Manual review path
  1. Download the JSON file and inspect it locally.
  2. Send it to the Town Reboot maintainer with the source link or open a repository issue.
  3. The maintainer checks relevance, source, wording, privacy and duplication.
  4. Accepted material is rewritten into the appropriate evidence layer with attribution and date. Rejected submissions are not published.
